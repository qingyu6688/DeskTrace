# DeskTrace

DeskTrace 是面向 Windows 的本地桌面工具，记录桌面上的文件和文件夹最近一次被打开、应用最近一次被使用的时间，展示应用的系统安装或更新日期，帮助用户找出值得整理的内容。

当前版本：`0.6.0`。前端已接入真实后端：概览、应用与桌面清单、详情、观察范围、排除规则、采集控制、持久化设置、CSV 导出和清除确认。默认登记系统桌面，用户启用后记录应用、资源管理器与“最近使用的项目”行为。完整完成情况与验收边界见 [功能完成情况](docs/功能完成情况.md)。首个正式版本计划为 `1.0.0`；安装包尚未实施。

## 当前结论

- 自行记录启用后的使用行为可行；Windows 不能保证提供启用前完整、准确的打开历史。
- 应用进入前台代表一次可观察的使用，后台进程运行不等于用户打开应用。
- 文件夹以资源管理器中的实际浏览记录为准；不把文件系统访问时间当成用户打开时间。
- 系统提供的应用日期可能是安装、更新或修复日期；首次发现时间单独保存。
- “很久没打开”展示为候选结果，并说明观察起点、数据来源与记录中断。

## 技术初选

`Tauri 2 + Rust stable + Vue 3 + TypeScript + Vite + SQLite`。

Windows 数据采集由 Rust 完成，前端通过本地 IPC 查询。SQLite 用于单用户本地存储，替代项目规范中的默认 MySQL；原因见技术选型说明书。Windows 11 多标签页识别和应用归属匹配必须先通过技术原型验证。

## 本地开发

前端代码、依赖和构建配置位于 `frontend/`；Rust workspace、Tauri 和数据库迁移位于 `backend/`。开发文档保留在根目录 `docs/`，独立静态原型 `UI/` 按用户要求保留原位置。

在项目根目录 `F:\桌面\DeskTrace` 的 PowerShell 执行：

```powershell
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend tauri dev
```

桌面程序启动后读取真实应用清单，首次自动加入系统桌面并登记直接子项；开始记录由用户主动启用。列表、轨迹和设置通过 Tauri IPC 读写本地 SQLite，界面不再填充演示样本。开机启动默认关闭。

仅预览前端，在项目根目录执行 `pnpm --dir frontend dev`，访问 `http://127.0.0.1:1420/`；浏览器显示未连接桌面程序、空清单与禁用的原生操作。Vite 预览与 Tauri 开发使用同一端口，切换启动方式前先关闭已有开发服务器。

前端检查在 `frontend/` 执行 `pnpm test`、`pnpm build`、`pnpm lint`；Rust 检查在 `backend/` 执行 `cargo test --workspace`、`cargo build --workspace`、`cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`。完整命令与产物位置见部署说明文档。

## 当前进度与下一阶段

后端在 `backend/` 中分为四层：`desktrace-core` 放与平台无关的规则，`desktrace-storage` 负责 SQLite 读写与查询，`desktrace-windows` 封装系统接口，`src-tauri` 提供 IPC、采集调度和托盘。规则与存储有自动化测试，系统接口有本机冒烟测试。

下一阶段：按测试计划完成原生对话框、资源管理器多窗口/多标签切换的实机真值用例，以及托盘、开机启动、性能和安装包验收。
