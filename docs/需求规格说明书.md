# 需求规格说明书

版本：`0.5.0`。日期：2026-10-11。状态：首期需求基线；0.5.0 起以桌面上的文件和文件夹为主要观察目标。

## 1. 产品目标与假设

以桌面上的文件和文件夹为主要目标，记录它们最近一次被打开或浏览，同时记录应用最近使用并展示安装时间线索，筛选较久未记录到使用的内容。首期按 Windows 11 x64、单设备、当前用户、离线本地运行设计。观察范围默认是当前用户的系统桌面，用户可以再添加其他文件夹；范围根目录下的每个直接子项（文件或文件夹）各是一个对象，不扩展到整盘的每个文件。

“最近打开”采用可观察口径：应用进入前台或处于用户活跃使用状态；文件夹在资源管理器活动标签页中被浏览；文件在打开时被系统登记到“最近使用的项目”。界面分别写“最近使用”和“最近浏览”，详情说明来源，不承诺精确的每次进程启动或目录打开动作。

## 2. 用户与使用场景

只有本机当前用户一个角色，无管理员后台和账户体系。

1. 用户首次运行，阅读记录范围，选择需要观察的文件夹范围并启用采集。
2. 用户查看应用清单，了解最近使用、系统安装/更新日期以及未知数据。
3. 用户按 90 天筛选，核对候选，排除长期保留的工作工具和目录。
4. 用户打开对象位置或进入 Windows 应用设置，自己整理或卸载。
5. 用户暂停记录、关闭开机启动、导出结果或清除本工具数据。

## 3. 功能要求

| 编号 | 功能 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-01 | Win32 与当前用户 MSIX 应用清单 | P0 | 有名称、来源、版本、可用身份；部分失败有提示 |
| FR-02 | 应用日期线索 | P0 | 日期、精度与含义可见；缺失显示未知 |
| FR-03 | 应用前台使用记录 | P0 | 支持范围内正确关联；后台运行不刷新使用 |
| FR-04 | 观察范围 | P0 | 首次启动自动加入系统桌面（支持重定向）；可再添加多个目录，可停用或删除桌面范围；可勾选包含子目录 |
| FR-05 | 资源管理器浏览记录 | P0 | 当前活动文件夹；不包含子目录时，深处的浏览记到范围根下的直接子项；标签页识别受原型结果约束 |
| FR-15 | 桌面文件打开记录 | P0 | 范围直接子项全部列出；文件打开以系统“最近使用的项目”为来源；程序、快捷方式等记录不到的类型显示无法判断；系统关闭该来源时文件结论改为无法判断并提示开启方法 |
| FR-06 | 长期候选筛选 | P0 | 默认 90 天；区分旧记录、从未记录、观察不足和未知 |
| FR-07 | 搜索、排序、分页 | P0 | 名称/路径搜索；未知时间单独排序；后端分页 |
| FR-08 | 排除与恢复观察 | P0 | 精确对象排除；目录可排除子树；恢复后重新建立观察起点 |
| FR-09 | 采集控制与托盘 | P0 | 启用、暂停、恢复、明确退出；模块故障可见 |
| FR-10 | 开机启动 | P0 | 用户可选，默认关闭；关闭主窗口仍有托盘状态 |
| FR-11 | 对象操作 | P0 | 打开受支持目录、定位路径、进入系统应用设置 |
| FR-12 | 导出与清除记录 | P0 | 当前筛选结果 CSV；明确字段；可清除本工具数据 |
| FR-13 | 历史线索导入 | P1 | 后续实现；默认关闭，不改写直接观察时间 |
| FR-14 | 磁盘占用统计 | P1 | 后续手动计算，有取消与缓存；不默认遍历整盘 |

应用支持列表按实际可解析身份确定；无法映射的应用仍展示清单，但不能判为从未使用。便携应用在观察到受支持的前台入口时建立对象，安装日期为空。

范围根目录下的直接子项在启动、范围变化时和每 10 分钟扫描登记一次，从未打开过的桌面文件也会出现在列表里；不预先扫描整盘，也不扫描子目录内部。更深的子目录只有在包含子目录的范围中被浏览到时才单独成为对象。

## 4. 时间与数据口径

| 数据 | 定义 | 显示原则 |
| --- | --- | --- |
| 最近使用/浏览 | DeskTrace 直接观察到的最近受支持行为 | 显示来源与观察时间；不是完整历史 |
| 系统日期 | 系统安装登记或包安装/更新时间 | 界面用“安装/更新日期”，含义不确定时写明 |
| 首次发现 | DeskTrace 第一次发现对象 | 不替代安装日期 |
| 开始观察 | 对象进入当前观察范围且模块准备就绪的时间 | 作为观察不足判断依据 |
| 日期精度 | 日期级或时间级 | 只有日期时不伪造 00:00 的精确安装时间 |
| 记录中断 | 暂停、退出、故障、未知期间 | 候选与详情显示，中断不算连续证据 |

时间戳存 UTC，界面按用户系统时区显示。一天的阈值按 86400 秒计算，详情标明阈值口径；日期级安装信息原样保存，不参与秒级计算。

## 5. 候选状态

| 状态 | 条件概述 | 用户文案 |
| --- | --- | --- |
| `recent` | 最近直接观察时间在阈值内 | 近期有使用记录 |
| `stale_candidate` | 观察跨度达到阈值，最后直接记录早于阈值 | 较久未记录到使用 |
| `never_observed` | 观察跨度达到阈值、来源可用，尚无直接记录 | 观察期内未记录到使用 |
| `insufficient_observation` | 观察跨度未达到阈值 | 观察时间不足 |
| `unknown` | 无有效观察起点、身份或来源不支持 | 无法判断 |
| `excluded` | 用户明确排除 | 已排除 |
| `unavailable` | 确认对象失联，或本轮无法访问 | 已失联/暂不可访问，详情区分原因 |

`stale_candidate` 和 `never_observed` 是整理候选，携带 `continuous/partial/unknown` 记录覆盖标识。覆盖未知时只能作为线索；筛选可以选择只看连续记录。禁止使用“永久未使用”“可安全删除”等结论。

打开对象或启动应用的请求成功，不代表已完成使用。只有采集确认的前台行为更新最近时间；操作系统拒绝请求时返回清晰提示。

## 6. 页面要求

- 概览：采集状态、观察起点、候选数量、记录缺口，首次使用突出观察不足。
- 桌面与文件夹列表：文件和文件夹一起列出；名称、路径、最近打开/浏览、开始观察、候选状态、覆盖情况、排除操作。
- 应用列表：名称、版本、最近使用、安装/更新日期、日期来源、候选状态。
- 对象详情：身份、直接记录、日期快照、来源限制、记录中断和排除状态。
- 设置：范围、阈值、保留天数、开机启动、暂停记录、数据目录、导出/清除。

以表格和清晰筛选为主。加载有阶段进度；空列表说明如何加入范围；部分数据源失败保留可用结果；错误文案不展示原始系统堆栈。

## 7. 非功能要求

| 编号 | 要求 | 验证方式 |
| --- | --- | --- |
| NFR-01 | 默认普通用户运行，不访问其他用户会话 | 标准账户实机验证 |
| NFR-02 | 本地存储，无默认联网、遥测和账号 | 运行流量与权限检查 |
| NFR-03 | 不采集文件正文、键盘内容、网页内容、窗口标题 | 代码审查与数据库字段检查 |
| NFR-04 | 采集与数据库任务不阻塞界面 | 故障注入和响应时间测试 |
| NFR-05 | 去重、分页、批量写入，数据量有上限策略 | 压力用例和保留任务 |
| NFR-06 | 清除/排除后不自动恢复被删除历史 | 回归测试 |
| NFR-07 | 所有产品文案、错误和代码注释中文 | 文案检查 |

性能数字为待验证目标，见测试计划；当前没有实测产品性能。

## 8. 首期范围外

不直接删除文件夹或卸载应用，不做云端同步、企业审计、隐蔽记录、磁盘驱动监听和全文件历史追踪。既有 Windows 历史不保证恢复。网络盘、虚拟 Shell 项目和第三方管理器不作为首期长期判断对象。
