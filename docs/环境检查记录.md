## 4. 本地配置计划

首期不配置数据库主机、账户、密码或外部 Token，不需要 `.env`。用户设置保存于本地数据库；生产数据目录通过系统 API 定位，计划落在 `%LOCALAPPDATA%\DeskTrace\`。

开发阶段仅预留以下配置，不在本次创建文件：

| 名称 | 用途 | 要求 |
| --- | --- | --- |
| `DESKTRACE_DATA_DIR` | 测试专用数据目录 | 仅开发/测试生效，必须是当前用户可写本地绝对路径 |
| `RUST_LOG` | 开发日志级别 | 发布包使用固定默认级别，不记录原始路径或窗口标题 |

后续如确需 `.env`，先写入 `.gitignore`；示例文件只写占位值，不写真实凭据。
