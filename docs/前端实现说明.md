# 前端实现说明

版本：`0.6.0`。日期：2026-10-11。状态：已接入后端业务命令，运行时使用真实数据。

## 1. 页面与数据来源

依据根目录 `UI/overview.html`、`UI/applications.html`、`UI/styles.css` 和 [UI 设计说明](../UI/UI设计说明.md) 实现。原型保留原位置，Vue、TypeScript、Naive UI、Pinia 与 Vue Router 的依赖版本保持不变。

| 地址 | 页面 | 真实数据与操作 |
| --- | --- | --- |
| `/#/` | 概览 | 三类对象候选分布、模块状态、清单刷新、观察范围、记录缺口、数据库计数 |
| `/#/applications` | 应用 | 名称/入口搜索、日期来源、状态与覆盖筛选、排序、分页、导出、清单刷新 |
| `/#/folders` | 桌面与文件夹 | 文件和文件夹合并查询；可切换仅文件/仅文件夹；添加观察范围 |
| `/#/objects/:id` | 独立详情 | 后端 UUID 查询、轨迹、安装证据、对象标识、事件分页、排除/恢复和原生定位 |
| `/#/settings` | 设置 | 持久化设置、系统桌面/普通范围管理、排除规则、清除确认、任务进度 |

路由按需加载。宽度达到 1260 像素时列表右侧显示详情，较窄时点击行打开抽屉。上下方向键切换当前页对象，行上 Enter 打开独立详情；抽屉保留焦点并支持 Esc。

## 2. 启动与数据边界

在项目根目录的 PowerShell 执行：

```powershell
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend tauri dev
```

桌面启动读取应用清单，首次加入系统桌面并登记直接子项。首次尚未开始记录时，由用户点击顶部“开始记录”；暂停和恢复均调用后端，重启后保持采集意图。

单独执行 `pnpm --dir frontend dev` 只预览网页，地址为 `http://127.0.0.1:1420/`。浏览器显示未连接桌面程序，清单保持为空、原生操作禁用。运行时没有演示开关或样本回退；旧样本已移入 `frontend/tests/fixtures/`，仅供回归测试使用。

调试隔离数据可设置进程级 `DESKTRACE_DATA_DIR`，详见 [部署说明](部署说明文档.md)。生产数据存放在当前用户的本地目录。

## 3. 请求、模型与刷新

| 文件 | 职责 |
| --- | --- |
| `frontend/src/api/client.ts` | Tauri 检测、统一返回信封、中文传输错误、保留业务错误码、事件订阅 |
| `frontend/src/api/workspace.ts` | 所有业务命令参数封装，组件不直接调用 invoke |
| `frontend/src/types/ipc.ts` | 查询、摘要、详情、范围、设置、任务等 DTO |
| `frontend/src/utils/adapters.ts` | DTO 转展示对象，保留后端候选状态、覆盖与说明 |
| `frontend/src/stores/workspace.ts` | 共享设置、概览、采集状态、范围、排除和任务；管理订阅生命周期 |
| `frontend/src/hooks/useResource.ts` | 页面异步资源；查询切换或卸载时使旧请求失效 |
| `frontend/src/components/JobPanel.vue` | 清单刷新/导出的进度、结果、失败信息及取消请求 |

分类、覆盖、范围归属、身份和安装日期校验以 Rust 返回为准。前端只格式化和绘制，不根据空的最近时间再次判断长期未用。

订阅 `objects-updated`、`collector-status-changed`、`job-progress`。对象通知在 300 毫秒内合并刷新；每 30 秒补查共享数据，每 3 秒补查活动任务，补偿早于订阅的任务事件。离开应用时注销订阅和定时器，部分订阅失败也会清理后重试。快速切换查询时较慢的旧响应不能覆盖新列表或新详情。

## 4. 查询和详情

- 后端分页每页 50 项，支持名称/路径关键词、七类状态、连续覆盖和四个排序字段；无时间对象由后端始终置后。
- 概览与状态按钮计数来自完整类型汇总；筛选结果数量来自分页返回的 `total`，两者口径不同。
- 应用使用 `application` 查询；桌面页默认 `location` 同时查询文件与文件夹，也支持 `file`、`folder`。
- 页面阈值支持 30/90/180 天和 1～3650 天自定义，只影响当前查询；设置页保存默认值。
- 详情按对象 ID 独立读取，不依赖对象是否位于已加载的列表页；使用事件每页 20 项。
- 轨迹窗口、每日记录与缺口来自后端。超过一年按周绘制，刻度不表示次数或时长；`source_disabled` 和合成 `unverified` 原因保留。
- 无效/缺失安装日期不回填；日期证据保留来源、精度、含义、校验结果与读取时刻。

打开所在位置、Windows 应用设置、最近项目设置均调用后端原生入口。文件和应用的定位采用后端验证的路径，不接受前端任意路径。目录树排除恢复前说明整棵树都会恢复，后端建立新的观察代次。

## 5. 设置与受控操作

保存阈值、原始事件保留天数和开机启动后才更新已生效状态；失败保留旧状态与编辑值，显示后端中文说明。开机启动默认关闭，只有用户保存变更才写入启动项。

范围添加先调用原生目录选择器，后续只发送 60 秒有效的一次性选择凭证；取消选择不新增，过期需重选。系统桌面可一键加回，列表支持停用、含子目录和移除；系统桌面固定为直接子项。移除保留对象历史。

导出前选择九个允许字段，再调用原生保存窗口。后端导出当前筛选的所有分页，负责 CSV 转义、公式防护、临时文件和取消清理。前端显示任务真实进度，总量未知时不显示虚假百分比。

清除采用两阶段流程：先准备并显示受影响对象数，再由用户确认后发送凭证。取消不清除；过期或数据版本冲突必须重新发起，不自动重试清除。仅清除本工具使用事件和观察区间，保留对象清单、设置、范围及排除规则。
