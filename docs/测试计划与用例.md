# 测试计划与用例

版本：`0.6.0`。日期：2026-10-11。状态：前后端联调与规则/存储回归通过；原生场景完整实机矩阵、性能和发布验收待完成。

## 1. 分层验证

核心规则、时间、路径边界与事务行为做自动化测试。Windows 原生采集做实机测试，不能用模拟事件证明系统覆盖。前端工具和组件测试命名为 `*.test.ts` 或 `*.spec.ts`；E2E 计划放在 `frontend/tests/e2e/`，Rust 库测试跟随 `backend/crates/` 中各 crate。

核心工具目标覆盖率不低于 80%，重点检查实际边界，而非复制实现过程。每个缺陷增加对应回归。文档写完不能替代功能测试，采集原型未通过不能进入发布。

## 3. 原型样本与矩阵

首轮使用当前 Windows 11 Build 26200 x64，至少再覆盖一个仍受支持的 Windows 11 构建，以实测结果建立支持矩阵，不预先承诺全部 Win11 版本。

选 10 个可复核测试应用，每个执行 10 次前台激活，包含普通 Win32、MSIX、便携程序、多进程程序和提升权限样本。要求支持场景无错归属，未解析项有清晰状态；不能通过自动提高权限掩盖失败。

目录操作样本包含单窗口、多窗口、活动标签切换和地址栏导航，各操作记录独立真值。人工计时或外部实验日志作为真值，不用本工具自身日志证明自身正确。

系统时钟、磁盘满、清单异常和安装更新实验在测试账户或隔离环境完成，不直接变更用户日常配置。

## 4. 性能目标

以下是验收目标，尚未测量。基准机器记录 CPU、内存、磁盘、系统版本与测试时其他负载；建议至少 4 核、16 GB 内存、SSD。

| 指标 | 目标 | 方法 |
| --- | --- | --- |
| 空闲采集平均 CPU | 10 分钟均值不超过 1% 总 CPU | 托盘驻留、无清单刷新，资源监视采样 |
| 托盘进程树内存 | 工作集目标不超过 100 MB | 含 WebView2 子进程，界面隐藏 10 分钟 |
| 界面可见进程树内存 | 工作集目标不超过 250 MB | 典型列表与详情交互 |
| 查询延迟 | 1 万对象、100 万原始事件时 P95 不超过 500 ms | 本地数据夹具，分页与候选查询 |
| 界面打开 | 暖启动首次可用列表目标不超过 3 秒 | 不等待完整清单刷新 |
| 事件持久化 | 正常负载下观察后目标不超过 2 秒提交 | 事件时间与事务完成时间对照 |
| 前台记录延迟 | 应用目标不超过 2 秒；文件夹目标不超过 3 秒 | 外部真值日志，注明采样漏记 |

若目标失败，先检查采样、重复事件、SQL 和 WebView 生命周期；没有新变更或未解决疑点时不反复跑全套测试。

## 5. 构建与发布检查计划

前端在 `frontend/` 运行单元测试、构建和 lint；Rust 在 `backend/` 运行测试、格式检查与 clippy。Tauri CLI 脚本支持从前端定位后端并构建桌面程序，具体命令见部署说明。发布模式、正式安装包及分发仍需独立验证。

Tauri WebView 上的系统交互不能仅靠浏览器 Playwright 测试证明。网页逻辑可自动化，Windows 原生窗口、托盘、系统设置和标签页采集按实机矩阵检查。

### 0.6.0 桌面联调记录

环境：Windows 11 Build 26200 x64，开发构建打包实际前端资产，通过 WebView2 调试协议操作页面；IPC 由真实 Tauri 后端处理，没有注入样本响应。使用 `backend/target/integration-0.6.0/` 测试库，真实清单快照为 146 个应用、60 个文件夹、44 个文件。

20 项检查：真实概览、首次启用入口、开始/暂停状态、分页/详情、后端状态依据、搜索空结果、排除/恢复、独立详情、文件类型、窄屏抽屉/Esc、设置写入、范围停用/恢复、移除/加回桌面、清除准备/取消、确认清除、清单任务、导出字段确认/取消、重启保留设置与采集意图、最终资产日期/宽度、第二页与末页数量。界面异常和未处理 Promise 拒绝均为 0。

设置实测保存阈值 180 天、保留 365 天，开机启动保持关闭；清除仅作用于测试库，并确认范围、清单和设置保留。未修改 Windows 最近项目设置；本机该来源关闭，文件实际打开采集仍待支持环境验证。

目录选择与导出保存的原生窗口、导出落盘组合流程、开机启动、Windows 设置跳转、托盘以及多窗口/多标签真值矩阵仍待完整人工验收。当前记录不宣称已达到性能或发布目标。
