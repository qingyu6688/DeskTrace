# 项目计划书

版本：`0.6.0`。日期：2026-10-11。状态：基础工程、后端实现和前端联调完成，完整实机矩阵与发布验收待推进。

## 1. 实施顺序

需求、技术选型、目录、数据库和接口已有文档基线。基础工程与后端采集已实现，前端已接入真实业务命令，完成情况见 [功能完成情况](功能完成情况.md)。阶段 0 的单窗口冒烟已执行，多标签、应用归属与完整生命周期矩阵仍待验收；当前不宣称达到正式发布条件。

| 阶段 | 工作 | 产出 | 预计工作量 |
| --- | --- | --- | --- |
| 阶段 0 | Win11 标签页、前台应用、安装日期原型 | 支持矩阵、失败场景与采集决策 | 3～5 人日 |
| 阶段 1 | 修订设计、建立工程与本地存储 | Tauri/Vue 工程、首个迁移、IPC 类型、基础测试 | 4～6 人日 |
| 阶段 2 | 应用、目录、候选、托盘与设置 | 首期功能、模块测试、操作手册修订 | 6～9 人日 |
| 阶段 3 | 实机回归、资源测试、打包与恢复 | 测试报告、安装包、部署说明、发布记录 | 5～8 人日 |

总计 18～28 人日，不包含云端、第三方文件管理器、完整历史解析或发布审核等待。多标签页适配受阻时先重估，不固定完成日期。

## 2. 原型任务

| 编号 | 实验 | 必须解决的问题 |
| --- | --- | --- |
| SPIKE-01 | Explorer Shell COM | 活动标签页是否唯一可识别，导航是否及时，虚拟目录如何过滤 |
| SPIKE-02 | 前台窗口与进程身份 | Win32、MSIX、多进程、提升权限应用是否正确归属 |
| SPIKE-03 | 安装清单与日期 | 当前用户/本机、32/64 位视图、空值、更新覆盖和重复入口 |
| SPIKE-04 | 生命周期与资源 | 托盘驻留、暂停、锁屏、休眠、异常退出与低开销 |

原型只读取必要系统信息，不执行卸载、不改注册表、不变更 NTFS 策略。样本和报告使用测试对象，不保留个人应用清单或私人路径。

## 3. 里程碑验收

阶段 0：达到可行性报告的原型条件；无法达到的场景明确移出支持范围。

阶段 1：前后端类型一致；设计 SQL 可迁移；数据写入和聚合事务有测试；构建与静态检查通过。

阶段 2：P0 功能可串成完整流程；无历史对象不会被错误判为长期未使用；排除、暂停、导出与清除行为经过验证。

阶段 3：发布构建、Windows 安装/卸载、数据保留/恢复与支持矩阵验证通过；版本号和文档同步。首个正式版使用 `1.0.0`，原型/预发布版本使用 `0.x`。

## 4. 文档维护

功能调整同时更新需求、设计、接口、数据库和用例。测试计划记录预期，测试报告记录实际结果，不能把未执行用例标为通过。每次发布写明版本、日期、变更、已知限制与验证环境。

项目阶段结束补充总结，记录采集覆盖的实际边界、误判处理和后续优先级。维护备注：`maorongkang@gmail.com`。
